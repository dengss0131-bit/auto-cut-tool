# Auto Cut Tool v1 - 口播自动粗剪工具

一个本地运行的口播视频自动去停顿工具。它可以检测口播素材中的静音/低音量停顿，自动缩短长停顿，生成剪后预览，并在用户确认后导出最终 MP4。

> 当前版本定位：口播视频“自动粗剪助手”，适合先完成机械性的停顿清理，再导入剪映、Premiere、DaVinci 等软件继续精修。

## 功能特性

- 点击选择本机视频文件，不需要手动输入路径
- 自动检测静音/低音量停顿
- 自动生成保留片段，将长停顿缩短为自然停顿
- 三种剪辑模式：自然、标准、紧凑
- 支持自定义静音阈值、停顿保留时长、字头字尾保护时间
- 先生成剪后预览视频，不直接覆盖或导出最终结果
- 页面内播放剪后预览
- 剪辑摘要卡片：原始时长、预览时长、删除时长、压缩比例、删除片段数
- 删除片段列表，支持点击“播放附近”快速检查切点
- 用户确认满意后，再导出最终 MP4
- 同时输出 JSON 剪辑报告

## 项目结构

```text
auto-cut-tool/
├─ app/
│  ├─ autocut.py          # 核心剪辑逻辑：检测静音、生成片段、调用 ffmpeg 导出
│  ├─ server.py           # 本地 Web 服务：上传、预览、导出接口
│  └─ web/
│     └─ index.html       # 前端页面
├─ outputs/               # 最终导出视频和报告，运行后生成
├─ previews/              # 剪后预览视频和报告，运行后生成
├─ uploads/               # 上传的源视频，运行后生成
├─ .gitignore
├─ VERSION
└─ README.md
```

## 环境要求

### 1. Python

推荐使用 Python 3.10 或 3.11。

> 注意：当前服务端使用了 Python 标准库 `cgi` 解析本地上传。Python 3.13 已移除 `cgi`，因此不建议使用 Python 3.13 运行本项目。

检查：

```bash
python --version
```

### 2. ffmpeg / ffprobe

本工具依赖 ffmpeg 和 ffprobe 处理视频。

检查：

```bash
ffmpeg -version
ffprobe -version
```

如果命令不可用，请先安装 ffmpeg，并确保它已加入系统 PATH。

Windows 推荐安装方式之一：

```bash
winget install Gyan.FFmpeg
```

安装后重新打开终端，再检查 `ffmpeg -version`。

## 快速开始

进入项目目录：

```bash
cd auto-cut-tool
```

启动本地服务：

```bash
python app/server.py
```

如果你的电脑同时安装了多个 Python，建议明确使用 Python 3.10，例如：

```bash
C:/Users/Administrator/AppData/Local/Programs/Python/Python310/python.exe app/server.py
```

启动成功后，终端会显示：

```text
口播自动粗剪工具已启动：http://127.0.0.1:8787
按 Ctrl+C 停止
```

然后在浏览器打开：

```text
http://127.0.0.1:8787
```

## Web 页面使用教程

### 第一步：选择视频

点击页面左侧的“选择文件”，选择本机视频，例如：

```text
.mp4 / .mov / .mkv / .avi / .m4v
```

### 第二步：选择剪辑模式

默认推荐使用：

```text
标准：推荐默认
```

三个模式区别：

| 模式 | 适合场景 | 剪辑倾向 |
|---|---|---|
| 自然 natural | 想保留更多呼吸感 | 少剪一点 |
| 标准 standard | 大多数口播 | 平衡推荐 |
| 紧凑 tight | 短视频快节奏口播 | 剪得更狠 |

### 第三步：可选调整高级参数

如果不懂参数，保持为空即可，系统会按模式自动使用默认值。

| 参数 | 说明 | 建议 |
|---|---|---|
| 最短停顿秒数 | 超过多久的静音会被处理 | 0.28 - 0.65 |
| 保留停顿秒数 | 每个长停顿最终保留多少 | 0.08 - 0.20 |
| 静音阈值 dB | 低于多少音量视为静音 | -38 到 -32 |
| 字头字尾保护秒数 | 防止切掉字头字尾 | 0.04 - 0.08 |

如果背景噪声很大，可以把静音阈值调高一些，例如：

```text
-32
```

如果剪得太狠，可以改用“自然”模式，或把“最短停顿秒数”调大。

### 第四步：生成剪后预览

点击：

```text
生成剪后预览
```

系统会：

1. 把源视频保存到 `uploads/`
2. 检测静音/停顿
3. 生成剪后预览视频到 `previews/`
4. 生成 JSON 报告
5. 在页面右侧显示剪后预览播放器

### 第五步：检查剪辑结果

右侧会显示：

- 剪辑摘要卡片
- 剪后预览视频
- 删除片段列表
- 每个删除片段的“播放附近”按钮

建议重点检查：

1. 是否有吞字
2. 是否剪得过于急促
3. 长停顿是否被有效缩短
4. 删除片段列表里是否有异常长的删除段

如果不满意，可以调整模式或参数，再点击：

```text
重新生成预览
```

### 第六步：确认并导出

预览满意后，填写导出文件名，然后点击：

```text
确认并导出
```

最终视频会保存到：

```text
outputs/
```

同时，如果存在对应报告，也会复制到 `outputs/`。

## 命令行使用

如果不需要 Web 页面，也可以直接用命令行处理视频：

```bash
python app/autocut.py "D:/path/to/input.mp4" --mode standard
```

指定输出路径：

```bash
python app/autocut.py "D:/path/to/input.mp4" --output "D:/path/to/output.mp4" --mode standard
```

自定义参数：

```bash
python app/autocut.py "D:/path/to/input.mp4" --min-silence 0.4 --keep-silence 0.12 --threshold-db -35 --padding 0.06
```

## 默认模式参数

| 模式 | 最短停顿 | 保留停顿 | 静音阈值 | 保护时间 |
|---|---:|---:|---:|---:|
| natural | 0.65s | 0.20s | -38 dB | 0.08s |
| standard | 0.42s | 0.12s | -35 dB | 0.06s |
| tight | 0.28s | 0.08s | -32 dB | 0.04s |

## 输出文件说明

运行过程中会生成三个目录：

```text
uploads/    # 上传的原始视频
previews/   # 剪后预览视频和报告
outputs/    # 用户确认后的最终导出视频和报告
```

这些目录属于运行产物，默认不会提交到 Git。

## JSON 报告字段

每次生成预览或命令行导出时，会生成一个 `.json` 报告，主要字段包括：

```json
{
  "input": "源视频路径",
  "output": "输出视频路径",
  "original_duration": 632.4,
  "estimated_output_duration": 488.2,
  "removed_duration": 144.2,
  "compression_ratio": 0.772,
  "params": {},
  "keep_segments": [],
  "removed_segments": []
}
```

其中：

- `keep_segments`：最终保留的视频片段
- `removed_segments`：被删除或缩短的停顿片段

## 常见问题

### 1. 页面显示 Failed to fetch

通常是没有通过本地服务地址访问页面。

请确认你打开的是：

```text
http://127.0.0.1:8787
```

不要直接双击打开 HTML 文件，也不要使用静态预览地址。

### 2. Python 3.13 报错 No module named cgi

请换用 Python 3.10 或 3.11：

```bash
python3.10 app/server.py
```

### 3. 预览视频黑屏或无法播放

请确认：

1. 使用的是最新版本代码
2. 重新生成了预览视频
3. 浏览器访问的是 `http://127.0.0.1:8787`

本项目已经为预览接口增加了 HTTP Range 支持，并为 MP4 增加 `faststart`，正常情况下可以在页面内播放。

### 4. 剪得太狠怎么办

可以尝试：

- 改用 `natural` 模式
- 调大“最短停顿秒数”
- 调大“保留停顿秒数”
- 调大“字头字尾保护秒数”

### 5. 背景噪声大，检测不到停顿怎么办

可以尝试把静音阈值调高，例如：

```text
-32
```

数值越接近 0，越容易被判定为静音。

## 当前版本限制

- v1 主要处理静音和低音量停顿
- 还没有做“嗯、啊、呃”等气口/填充词识别
- 还没有口误重说识别
- 还没有剪映草稿导出
- 对高噪声环境素材，需要手动调参数
- 当前 Web 服务是本地工具，不建议暴露到公网
